# NTI Summer Training — Computer Vision Tasks

Tasks completed during the [National Telecommunication Institute (NTI) Summer Internship Program](https://www.nti.sci.eg/summertraining/).

## Contents

| # | Task | Description |
|---|------|-------------|
| 1 | [Knee Osteoarthritis Classification](01-osteoarthritis-classification-cnn/knee-osteoarthritis-cnn.ipynb) | CNN-based severity classification of knee osteoarthritis from X-ray images |
| 2 | [CNN Architectures Comparison](02-cnn-architectures-comparison/inception-resnet-mobilenet.ipynb) | Comparing Inception, ResNet, and MobileNet architectures |
| 3 | [VGG & Modified VGG](03-vgg-modified-vgg/vgg-modified-vgg.ipynb) | VGG implementation and a modified variant |
| 4 | [Object Detection (YOLO)](04-object-detection-yolo/yolo-object-detection.ipynb) | Object detection using YOLO, trained via Roboflow-hosted dataset |
| 5 | [Brain Tumor Segmentation](05-brain-tumor-segmentation/brain-tumor-yolov8-seg.ipynb) | Instance segmentation of brain tumors using YOLOv8-seg |
| 6 | [Landscape Colorization (U-Net)](06-landscape-colorization-unet/landscape-colorization-unet.ipynb) | Grayscale-to-color image colorization using a U-Net architecture |

## Notes

- Notebooks were originally developed on Kaggle/Colab; dataset paths reference `/kaggle/input/...` and may need adjusting to run locally.
- `04-object-detection-yolo` requires a Roboflow API key — set it via environment variable or replace the `YOUR_ROBOFLOW_API_KEY` placeholder in the notebook rather than hardcoding it.
